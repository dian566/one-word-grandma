# One Word From Grandma — Witchcraft

A one-word entry for the make.fun bounty of the same name. Asked
what she thinks of AI, grandma types a single word: the machine must
be witchcraft, because nothing else explains it.

Running `python3 main.py` glues the two halves of the word and writes
the 10-character entry to `/output/entry.txt`. The file holds exactly
those 10 characters, with no trailing newline.
