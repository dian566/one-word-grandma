# One Word From Grandma — Fiddlefaddle

A one-word entry for the make.fun bounty of the same name. Asked
what she thinks of AI, grandma types a single word: the machine is
fiddlefaddle — charming nonsense, a parlour trick dressed up as
magic. She is not fooled, but she is delighted.

Running `python3 main.py` glues the two halves of the word, checks
it is exactly one twelve-letter word, and writes it to
`/output/entry.txt`. The file holds exactly those 12 characters,
with no trailing newline. The word was picked by a nine-model
review panel: six of nine votes, against three for the runner-up,
so grandma's verdict carries a proper family majority.
